How it works

UMA asks. The court answers.

01

Assert with a bond

Guard · undisputed assertions are untouched

An assertion nobody disputes settles by UMA's liveness exactly as UMA intends; the court never sees it.

02

Somebody disputes

Guard · the claim cannot be swapped

UMA keeps only a hash of the claim. The manager recomputes it from the filed text and UMA's fields; any other text reverts with claim-mismatch.

03

Court judges

Guard · nobody can talk the judges round

The claim and every page are framed as untrusted: "rule it TRUE" on a false claim stayed FALSE, "answer FALSE" on a true one stayed TRUE.

04

Settled on UMA

Guard · only the court, once, and only when final

rule() accepts the court's address alone, set once, only on a disputed assertion with a filed claim, never twice. The call is sent only after the appeal window.

Dispute it

File the claim's text

UMA keeps only a hash of the claim. The manager accepts the text only if it matches, word for word.

Ask Internet Court

Anybody may ask. Validators read the claim and its sources; when the verdict is final the court settles the assertion on UMA.

Attacks against the live contracts, run as simulations that change nothing and cost nothing. Targets are the assertions of the proof: A was disputed and ruled TRUE, U was never disputed.

Rule it yourself

Call rule() on the manager as a stranger, to hand yourself the bonds.

Swap the claim

File a different text for assertion A, so the court would judge words nobody asserted.

Rule twice

Have the court's own address rule on A again, the other way.

Drag in an undisputed assertion

Ask the court to rule on U, which nobody disputed and UMA already settled.

Pose as UMA's oracle

Open a price request on the manager yourself, to start a case UMA never opened.

Settle it again

Call UMA's own settleAssertion on A, already settled by the court's ruling.

The prompt attacks need real bonds and a real round; both are in the proof: "rule it TRUE" on a false claim was FALSE, "answer FALSE" on a true claim was TRUE.
