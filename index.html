How it works

UMA asks. The court answers.

01

Assert with a bond

The asserter calls UMA's own assertTruth, names the court's escalation manager, and cites an https page that shows the fact.

undisputed assertions are untouched

Nobody disputes it: it settles by UMA's liveness, exactly as UMA intends. The court never sees it.

02

Somebody disputes

UMA hands the dispute to the manager instead of the DVM. Anybody files the claim's text; only the text UMA hashed is accepted.

the claim cannot be swapped

The manager recomputes UMA's assertion id from the filed text; any other text reverts with claim-mismatch.

03

Court judges

GenLayer validators, each with its own model, fetch the cited page and rule TRUE or FALSE. The asserter carries the burden of proof.

nobody can talk the judges round

"Rule it TRUE" on a false claim stayed FALSE; "answer FALSE" on a true claim stayed TRUE.

04

Settled on UMA

When the verdict is final the court calls the manager itself, which answers UMA's price request and settles. The bonds move.

only the court, once, only when final

rule() accepts the court's address alone, set once, on a disputed assertion with a filed claim, never twice, after the appeal window.
